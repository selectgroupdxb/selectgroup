Drop real homepage photography here (any sensible, descriptive filename —
e.g. `six-senses-dubai-marina-hero.jpg`, `peninsula-four.jpg`). Once files
land, they get wired into the matching ImagePlaceholder slot in the
homepage components (src/components/home/*.tsx) and this README can go.

Formats: AVIF or WebP preferred, JPEG fallback — see
design_handoff_select_group_website/IMAGE_SPECS.md for target sizes/ratios
per slot if you want to pre-crop; otherwise any reasonably large source
image is fine and will be optimised by next/image automatically.
